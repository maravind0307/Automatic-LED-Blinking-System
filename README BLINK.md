## **1\. Abstract**

The Arduino LED Blink project is a basic electronics project that demonstrates how to control an LED using an Arduino board. In this project, an LED is connected to an Arduino through a breadboard and a resistor. The Arduino is programmed to turn the LED ON and OFF at regular intervals. This project helps beginners understand digital output, circuit connections, and basic Arduino programming.

## **2\. Description**

This project uses an Arduino board to control an LED connected through a breadboard. The LED is programmed to glow for one second and turn OFF for one second continuously. A resistor is used to limit the current flowing through the LED and protect it from damage. The project demonstrates the basic operation of digital pins in Arduino.

## **3\. Materials Required**

* Arduino Uno  
* Breadboard  
* LED  
* 220Ω resistor  
* Jumper wires  
* USB cable  
* Computer or laptop

## **4\. Procedure**

First, connect the LED to the breadboard. Connect the positive leg of the LED to Arduino digital pin 13 through a 220Ω resistor. Connect the negative leg of the LED to the Arduino GND pin. Connect the Arduino board to a computer using a USB cable. Open the Arduino IDE and write the LED blink program. Select the correct board and COM port, then upload the program to the Arduino. Observe the LED blinking continuously.

## **5\. Working Principle**

The Arduino sends a HIGH signal to the digital pin connected to the LED, causing the LED to glow. After one second, the Arduino sends a LOW signal, turning the LED OFF. This process repeats continuously using the delay() function. The resistor limits the current flowing through the LED and protects it from damage.
